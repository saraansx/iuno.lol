===============================================
 AUDIT FIXES — PRIORITIZED
===============================================

SECURITY (items 5-9)

5. No rate limits on pin/edit/delete comment
   togglePinComment, editComment, deleteComment are all spam-able.
   Fix: add per-user rate limits on each.

6. Coming-soon gate bypass
   path.includes(".") treats any path with a dot as a public asset.
   Usernames allow dots, so /john.doe bypasses the gate.
   Fix: check file extension on the last segment only.

7. Logout does not invalidate the session
   JWT stays valid for 7 days after logout. A stolen cookie survives logout.
   Fix: Redis denylist keyed by iat/jti on logout and password change.

8. No Content-Security-Policy header
   User bios are rendered via HTML. A future escaping regression becomes
   unmitigated stored XSS.
   Fix: add a CSP in the proxy.

9. .env has localhost values
   NEXT_PUBLIC_APP_URL, DISCORD_REDIRECT_URI, COMING_SOON_MODE all point
   to localhost. Deploying as-is breaks Discord login and hides the site.
   Fix: create a separate production env file with the real domain.


SCALE (items 10-15, fix when you grow)

10. Dashboard re-fetches 9+ queries per nav
    No caching on any of them.
    Fix: use unstable_cache or React cache().

11. flush-views cron processes profiles one-by-one
    Can exceed the 60-second maxDuration during a viral spike.
    Fix: batch process or fan out via QStash.

12. Admin bypass in URL query string
    Admin key sits in ?admin_access= (logged in server/access logs).
    Cookie lasts 1 year with no revocation.
    Fix: move to POST-only route, shorter cookie, add denylist.

13. Images served unoptimized
    images.unoptimized: true serves raw originals to every visitor.
    Fix: enable Next.js image optimization or pre-resize on upload.

14. Rate limiter is non-atomic
    5 sequential Redis calls. Concurrent bursts under-enforce the limit.
    Fix: use Lua scripting or Upstash ratelimit with sliding window.

15. Hardcoded .iuno.lol cookie domain
    Breaks sessions on any other domain (staging, custom).
    Fix: derive from NEXT_PUBLIC_APP_URL at runtime.


CLEAN (no action needed)

- Dead code: almost none. Only 4 minor items (unused User type, toast
  re-exports, duplicate cn(), duplicate hexToRgba).
- No orphaned files, no unused imports, no unused packages.
- All security headers except CSP are in place.
- CSRF protected via Next.js Server Actions (built-in).
- Upload has magic-byte sniffing and per-format size caps.
- View counting buffered in Redis, flushed by cron (off request path).
- DB indexes on hot queries.
- Rate limits on most critical paths (login, register, upload, etc).
- All heavy clients lazy-loaded via next/dynamic.
- Type-check, lint, build all pass.
